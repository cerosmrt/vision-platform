# Clientes — prospección

Una carpeta por negocio. Adentro de cada una:

- `ficha.md` — datos del negocio, estado actual e historial de contacto.
- `emails/` — un archivo por mail, nombrado `AAAA-MM-DD-que-es.md`. El que se mandó
  queda tal cual se mandó; los que todavía no salieron van marcados **BORRADOR**.

**Estados:** `sin contactar` → `enviado` → `respondió` / `sin respuesta` → `reunión` →
`cerrado` / `descartado`.

`sin respuesta` se pone recién a los 7 días del envío.
